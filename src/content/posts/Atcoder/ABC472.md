## A問題

**結果:** AC

1文字ずつ見て `A` を残し、それ以外を `.` に置き換える。

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    string s;
    cin >> s;

    for (char c : s) {
        cout << (c != 'A' ? '.' : 'A');
    }

    return 0;
}
```

別の書き方も試す。可読性は落ちる。

```cpp
for (char c : s) cout << ".A"[c == 'A'];
```

## B問題

**結果:** AC

左側の長さを `left`、全体を `sum` とすると、右側は `sum - left`。切る位置ごとに両側を足し直すと O(n²) かかるが、累積和なら各位置の差 `abs(sum - 2 * left)` を O(1) で計算でき、全体で O(n) になる。切れる位置は内部の `n−1` 箇所。制約下では長さの合計は最大 `10^7` なので、32ビット整数で途中計算も収まる。

```cpp
#include <algorithm>
#include <cstdlib>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> l(n);
    int sum = 0;

    for (auto& i : l) {
        cin >> i;
        sum += i;
        i = sum;
    }

    int ans = sum;

    for (int i = 0; i < n - 1; ++i) {
        ans = min(abs(sum - l[i] * 2), ans);
    }

    cout << ans << endl;
    return 0;
}
```

## C問題

**結果:** 未AC

解説で差分計算を知り、あとは自力実装した。提出時は `long long` が必要なことに気づかず未AC。掲載コードでは修正している。

直近 `M` 日間で食べた分の合計を持つ。日が進んだら当日分を加え、窓から外れた日を引く。当日分を拒否したときは、その日の値を0にしておく。そうすると、後で窓から外すときに拒否分を誤って引かずに済む。

例えば窓の長さが3日なら、4日目の判定では1日目の確定値を引き、4日目の候補を足す。拒否した3日目の値は0として扱う。

| 判定日 | 窓の内訳 | 合計の作り方 |
| --- | --- | --- |
| 3日目 | 1日目 + 2日目 + 3日目の候補 | 3日目を足す |
| 4日目 | 2日目 + 0 + 4日目の候補 | 3日目までの確定合計から1日目を引き、4日目を足す |

`M ≤ 2 × 10^5`、各値は最大 `10^9` なので、合計は最大で `2 × 10^14` になる。しきい値も最大 `10^15` まであるため、入力と集計を64ビット整数で扱う。掲載コードは前日分を引く前に当日分を足すので、中間値は最大で `(M+1) × 10^9` の上界を持つ。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

#define rep(i, n) for (int i = 0; i < (n); ++i)

using ll = long long;

int main() {
    ll n, m, k;
    cin >> n >> m >> k;

    vector<ll> a(n);
    for (auto& i : a) cin >> i;

    ll partial_sum = 0;

    rep(i, n) {
        partial_sum += a[i];
        if (i >= m) {
            partial_sum -= a[i - m];
        }

        if (partial_sum > k) {
            partial_sum -= a[i];
            a[i] = 0;
            cout << "No\n";
        } else {
            cout << "Yes\n";
        }
    }

    return 0;
}
```

掲載したA〜CのコードはApple Clang 21.0.0でC++17としてコンパイルし、公式の入力例9件で確認した。Cは合計が32ビットの符号付き整数の範囲を超えるケースでも確認した。修正版の再提出は行っていない。

同じ方法は、直近一定件数のアクセス数などを集計するときにも使える。窓に入る値と出る値だけを更新できることが条件になる。
