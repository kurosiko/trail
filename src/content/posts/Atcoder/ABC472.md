# ABC472

## A問題

**結果:** AC

解説とほぼ同じ解法だ。

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    string s;
    cin >> s;

    for (char c : s) {
        cout << (c != 'A' ? '.' : 'A');
    }

    return 0;
}
```

別の書き方も試す。可読性は落ちる。

```cpp
for (char c : s) cout << ".A"[c == 'A'];
```

## B問題

**結果:** AC

左側の長さを `left`、全体を `sum` とすると、右側は `sum - left`。切る位置ごとに両側を足し直すと O(n²) かかるが、累積和なら各位置の差 `abs(sum - 2 * left)` を O(1) で計算でき、全体で O(n) になる。

```cpp
#include <algorithm>
#include <cstdlib>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> l(n);
    int sum = 0;

    for (auto& i : l) {
        cin >> i;
        sum += i;
        i = sum;
    }

    int ans = sum;

    for (int i = 0; i < n - 1; ++i) {
        ans = min(abs(sum - l[i] * 2), ans);
    }

    cout << ans << endl;
    return 0;
}
```

## C問題

**結果:** 未AC

解説で差分計算を知り、あとは自力実装した。提出時は `long long` が必要なことに気づかず未AC。掲載コードでは修正している。

直近 `M` 件の受理分の合計を持つ。日が進んだら当日分を加え、窓から外れた日を引く。当日分を拒否したときは、その日の値を0にしておく。そうすると、後で窓から外すときに拒否分を誤って引かずに済む。

`M ≤ 2 × 10^5`、各値は最大 `10^9` なので、合計は最大で `2 × 10^14` になる。しきい値も最大 `10^15` まであるため、入力と集計を64ビット整数で扱う。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

#define rep(i, n) for (int i = 0; i < (n); ++i)

using ll = long long;

int main() {
    ll n, m, k;
    cin >> n >> m >> k;

    vector<ll> a(n);
    for (auto& i : a) cin >> i;

    ll partial_sum = 0;

    rep(i, n) {
        partial_sum += a[i];
        if (i >= m) {
            partial_sum -= a[i - m];
        }

        if (partial_sum > k) {
            partial_sum -= a[i];
            a[i] = 0;
            cout << "No\n";
        } else {
            cout << "Yes\n";
        }
    }

    return 0;
}
```

同じ方法は、直近一定件数のアクセス数などを集計するときにも使える。窓に入る値と出る値だけを更新できることが条件になる。
