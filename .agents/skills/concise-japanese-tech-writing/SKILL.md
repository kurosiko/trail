# 簡潔な技術記事の文体

技術記事を修正するときは、内容やコードを変えずに、短く簡潔な文体へ整える。

## 文体

- です・ます調を使わない
- 「まずは関数の準備」「命令を順に確認」のような体言止め・短文を使う
- 説明を一文一情報に分ける
- 「〜しています」「〜することができます」を避け、「〜を格納」「〜を確認」のように書く
- 接続詞や前置きを減らす
- 読者に必要な計算・理由・結論は省略しない

## コード解説

- コードブロックの内容は変更しない
- 各手順の説明の近くに、対応する実際のコードを置く
- レジスタやメモリの値は、コードの実行順に追う
- 16進数から10進数へ変換する場合は、必要なら両方を示す
- 最終結果やフラグは独立したコードブロックで示す

## 例

```text
まずは関数の準備

`eax` に値を読み込み、`0x4` を掛ける

計算結果をメモリに保存。もう一度 `eax` に読み込む

答えは `2619997`
```

記事全体を修正する場合、既存の見出し・コード・frontmatter・計算結果を維持し、口調と説明の冗長さだけを調整する。
